Qué hace el sistema

Datos de presión, traducidos.

El sistema usa sensores para alertar al conductor cuando detecta un problema de presión o no puede leer correctamente un sensor. La programación conecta información compatible del sensor con el vehículo.

Preguntas comunes

Antes de llamar.

Estas respuestas explican el punto de partida. El servicio específico depende del vehículo y sensor.

¿La luz de presión siempre significa que un sensor está dañado?

No. Puede indicar baja presión, cambios por temperatura, un problema de comunicación u otra condición. Se debe revisar antes de asumir la causa.

¿Se puede programar cualquier sensor de reemplazo?

La compatibilidad varía. Llame con año, marca, modelo e información del sensor para confirmar si corresponde.

¿Qué es un reaprendizaje de TPMS?

Es el proceso que usa el vehículo para reconocer posiciones o identificadores después de ciertos trabajos. Depende del vehículo.

¿Puedo seguir conduciendo con la luz encendida?

Revise las llantas de forma segura y siga las indicaciones del fabricante. Si una llanta está baja o dañada, o el vehículo se siente inseguro, deje de conducir y busque ayuda.
